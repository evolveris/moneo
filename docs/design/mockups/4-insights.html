Decisions shown: Behaviour is the first tab because it is where most time will be spent (D-038); horizontal bars for category (labels and values sit next to every bar, so nothing depends on colour); a "view as table" for every chart; income kept out of the spending chart; "No context" shown as an honest group; the coverage box links to the prompts below with "Add more context". Each of the 9 spending categories has its own colour (D-042): eight hues in a fixed order plus grey for Other, so a category keeps its colour in every chart. The palette was validated for the dark surface with the dataviz palette checker (all checks pass; colour-blind separation is in the 8.4 to 8.7 band, so direct labels, values, the legend and a table view are required, and are present).
